# RTX React — Refonte

Installe et lance le projet React + Vite + Tailwind.

Commands:

```powershell
cd rt-express/rtx-react
npm install
npm run dev
```

Contenu ajouté:
- `src/components/*` : `Hero`, `AnimatedSection`, `CTAButton`, `GlassCard`.
- `src/lib/initLenis.js` : smooth scroll init (optional).

Notes:
- Fournir `assets/videos/hero.webm` et un `poster` pour le hero si vous voulez la vidéo de fond.
- Ajustez `tailwind.config.cjs` pour votre identité (couleurs, fonts).
